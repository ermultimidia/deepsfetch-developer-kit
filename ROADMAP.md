# Próximas etapas para conquistar desenvolvedores

Esta é a ordem proposta de trabalho; as datas de entrega ainda não estão definidas.

- [ ] Publicar este kit e apontar o site para o repositório público.
- [ ] Validar cadastro, criação da chave e primeira coleta concluída com usuários independentes.
- [ ] Gravar uma demonstração curta com uma coleta real concluída.
- [ ] Publicar o SDK Python no PyPI e atualizar as instruções depois de verificar a instalação.
- [ ] Simplificar a extração e os IDs do MCP; depois validar cada cliente suportado.
- [ ] Registrar os metadados do MCP remoto no registro oficial e em diretórios selecionados.
- [ ] Publicar um caso de uso completo com n8n, fluxo importável e tutorial.
- [ ] Preparar o node comunitário para verificação pelo n8n conforme os requisitos atuais.
- [ ] Publicar um teste comparativo reproduzível com falhas, qualidade, tempo de resposta e custo.
- [ ] Avaliar um componente de coleta separado para hospedagem própria.

Medidas iniciais de sucesso: tempo até a primeira coleta concluída, usuários independentes que conseguem usar, taxa de segunda utilização e falhas de integração relatadas. Estrelas e downloads ajudam a acompanhar a divulgação, mas não substituem uso real.
